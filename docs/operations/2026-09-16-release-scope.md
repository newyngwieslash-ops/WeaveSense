## 2.1 微信公众号：当前不可用的实测证据（2026-09-17）

| 检查项 | 实测结果 |
|---|---|
| `wewe-rss` 服务（`127.0.0.1:4000`） | ✅ 在运行，Feed 可访问（HTTP 200，10 KB） |
| Feed 条目 | ✅ 38 条，解析后 24 条；标题 / 日期 / `mp.weixin.qq.com` URL 正确 |
| **Feed 正文** | ❌ **全部为空**（每条都是 `<description />`） |
| **上游库内正文** | ❌ `content_html` 非空 **0/154**、`summary` 非空 **0/154** |
| **同步历史** | ⚠️ **11 次 `risk_control` vs 5 次 `ok`**；错误为 `微信读书返回风控/限频错误 -2041` |
| 最后一次成功同步 | **2026-09-02**（距今 14 天） |

**结论**：微信采集当前拿不到正文，即使修好织识侧的网关白名单也只能入库标题，无法支撑分析与检索。
因此**首版不纳入微信**，直至上游风控解除或改用其他受控通道（如织识自身的付费兜底，需独立授权与费用）。

**织识侧另有一个独立障碍（已记录，未修）**：正在运行的网关容器里 `WECHAT_PRIMARY_ALLOWED_HOSTS=wechat-fixture`（QA 夹具值），
与真实源地址不匹配；网关会拒绝真实 Feed。此项待微信恢复后再处理，避免现在改动生产栈。

## 4. 明确排除（首版不做，不自动扩大范围）

- 多租户、跨用户协作、细粒度权限（无公网多人需求）
- 向量数据库 / 新 Agent 框架（现检索未证明不足）
- 独立浏览器爬虫、定制分享卡、更多导出形式
- 未经用户点名的平台适配器"凑数"实现
- 公网部署与身份认证（当前无登录，只能本机/受控内网）

## 5. 费用与调用边界

- 外部 MCP 保留现有能力，**默认未启用**。
- `AUTO_ANALYZE` 默认关闭；开启属独立授权。
- 真实模型/OCR/ASR/采集/微信付费调用全部需要 Gate A（T21）逐项授权，含金额与次数上限。
- 本范围表不含任何已批准的额度。

## 6. 用户需要决定的最小清单

1. 首版**实际启用**哪些平台（第 2 节中 proposed 项勾选）。
2. 真实模型服务与费用上限（T21/Gate A）。
3. 业务数据归属：以现有 PostgreSQL 容器为业务库，还是其他（T22/Gate B）。
4. 是否申请公网/多人使用（若是，需另做身份与权限，属新范围）。
