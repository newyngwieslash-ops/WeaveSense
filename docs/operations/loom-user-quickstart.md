## 1. 你会在哪里看到它

一个网页应用：左侧是导航（总览 / 内容库 / 关键词雷达 / 信源 / 任务 / 管道 / 节点 / 知识库 / 模型设置 / 指南）。

**启动方式**：由运行环境启动后，通过浏览器打开给出的地址即可。
（你不需要敲命令、装 Docker 或配置端口——那些是部署方的事。）

## 2. 五分钟走一遍

1. **总览**：看今日新增、信源与关键词数量、最近任务。
2. **信源**：添加一个 RSS 地址，或粘贴多个一次导入。
3. **关键词雷达**：输入行业词（如「固态电池」）→ 选择范围 → 设定间隔 → 保存。
   - 标「**检索**」的范围会发起外部查询；
   - 标「**信源**」的范围**只匹配已采集到的内容**，不发起外部请求。
4. **任务**：能看到每次采集的结果。**失败会显示原因**（例如「部分来源失败（hacker_news：rate_limited）」），不再把失败显示成"成功零条"。
5. **内容库**：筛选、搜索、打开详情；长文现在**保留全文尾部**。
6. **知识库**：生成简报、提问；回答只引用库内材料，外部来源会单独标注「服务来源」。

## 3. 触发真实服务的动作（需要先授权）

| 动作 | 会发生什么 | 何时可做 |
|---|---|---|
| 点「分析」条目 | 调用你配置的模型，产生费用 | **生产已接入，可直接用**；额度由你控制 |
| 点「生成简报」/ 提问 | 调用模型；若启用了工具研究，还会调用 MCP | 同上 |
| 提取图片/音视频（OCR/ASR） | 调用视觉/语音模型 | 同上（**需另行配置 `XAI_API_KEY`**） |
| 关键词「检索」范围 | 对外发起搜索请求 | **生产已在运行** |
| 微信付费兜底 | 调用付费供应商，**按次计费** | 默认关闭；无经验证上界时系统会**拒绝**而不是猜价 |

**默认状态**：自动分析关闭、自动提取关闭、付费兜底关闭、外部 MCP 未启用。这些都是刻意保守的默认值。

## 4. 常见问题

**Q：任务显示"全部失败"是什么意思？**
所有外部检索来源都失败了（网络、限流或接口变更）。本地已采集内容的匹配仍会照常进行，任务说明里会写明本地的命中数。

**Q：为什么我看不到 5 分钟档的实际效果？**
调度唤醒已缩短到 60 秒，但**每个源仍按自己的间隔采集**（5/10/30 分钟，微信源固定 60 分钟）。缩短唤醒只是让到期的源更快被发现，不会让采集频率翻倍——落盘、OCR、对账都各自保持原有节奏。

**Q：正文很长会不会被截断？**
存储层现在保留完整正文；模型侧另有上下文预算（那是模型的限制，不是内容被丢弃）。

**Q：回答会引用库外的东西吗？**
普通问答只引用库内材料；只有显式启用工具研究时才会出现外部来源，且会标注「服务来源」。

**Q：页面上的"在线"是不是就代表采集正常？**
不是。节点页的"在线"只表示服务可达；真正的采集结果要看**任务**页。这也是我们不在界面上过度承诺的原因。

**Q：刷新页面会不会丢失数据？**
取决于部署方式：使用 PostgreSQL 时会持久保存；如果是开发预览环境（内存数据库），**刷新保留、重启丢失**。生产使用必须配置数据库。

## 6. 出问题了看哪里

| 现象 | 先看 |
|---|---|
| 采集没有新内容 | 任务页的该源记录与其错误文本 |
| 关键词没有结果 | 任务页：区分"外部失败"与"确实没有命中" |
| 分析/问答失败 | 知识库页的错误提示；模型配置由运维方在服务端文件维护（应用内「模型设置」页在生产是只读的，这是设计） |
| 费用异常 | 微信网关的用量记录；未知结算会保持"未知"而不是记 0 |
| 系统整体状态 | `node scripts/operations-status.mjs`（运维方使用；非 0 退出表示有告警） |

## 7. 当前明确不承诺的能力

- 抖音 / 小红书 / 西瓜等**没有独立实现**的平台检索。
- YouTube 全站视频搜索：目前只经 Google News 的**新闻索引**查询。
- **微信公众号采集**：上游风控导致正文全空（0/154），**首版不纳入**。
- **公网多人使用**：当前没有账号体系。端口已收窄到本机（局域网不可达），
  但同宿主的其他进程仍可访问——多人/远程使用需先做身份层。
- 1000 信源的**持续**稳定运行：目前只有突发评测，长期运行证据待 Gate C。
