## 4. 现在测不了的（会明确提示，不会伪造结果）

| 功能 | 缺什么 | 补齐方式 |
|---|---|---|
| **OCR / ASR** | `XAI_API_KEY` 未配置（节点页显示"未配置"） | 需另行提供 xAI Key——注意它与同步模型（走本地网关）是**两条独立配置** |
| **抖音 / 小红书 / 西瓜检索** | 无内置全站检索（设计如此） | 仅自备 RSSHub/collector 地址时走同一管道 |
| **微信正文** | 上游风控 | 等风控解除或改用付费兜底（需单独授权） |
| **模型设置页** | 生产只读（设计要求） | 改模型需编辑 `F:/loom-backups/model.local.json` 后 `docker compose up -d --force-recreate --no-deps app` |

## 5. 测试时的三条注意

1. **费用**：分析和问答调真实模型（`gpt-5.6-luna`），每次按键才调用。自动分析（`AUTO_ANALYZE`）是关的，不会后台烧钱。
2. **失败会如实显示**：采集失败在任务页有具体错误码（如 B 站限流、TLS 断连）；**TLS 断连（36氪/量子位/Solidot）是本机网络瞬时问题**，下一轮自动重试，不必报障。
3. **别用局域网设备访问**：`http://<本机IP>:8080` 已不可达（加固收窄）。要在别的设备测，先告诉我，那需要重新评估暴露面。

## 6. 出问题先看哪里

| 现象 | 先查 |
|---|---|
| 页面打不开 | 双击 `restart.bat`；看 `artifacts/logs/restart.log` |
| 分析/问答报连接失败 | `opencodex health`（网关停了就 `opencodex start`；重启电脑后需手动启动，除非已装持久服务） |
| 采集没有新内容 | 「任务」页该源的错误文本 |
| 关键词没有结果 | 任务页区分「外部失败」vs「确实无命中」 |
| 容器不健康 | `docker ps` 看哪个；`docker logs <容器名>` 尾部 |

## 7. 一句话总结

Telegram 深度采集差一次账号登录；OCR/ASR 差一个 xAI Key；微信等上游风控；
