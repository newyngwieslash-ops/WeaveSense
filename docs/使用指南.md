1. 打开 **总览**。首页是深场白线指挥台。首次进入会自动接入示例信源并扫描到期任务。底边四个格子有数字即已就绪。

## 3. 接入信源

「信源 → 接入」。每个平台一个 collector，编排层负责间隔、重试和 `last_external_id` 游标。

- **RSS / Atom**：填 Feed URL。36氪、量子位、HN、Google News 等公开源可直接实采。
- **Telegram**：用频道**用户名**接入，不要用聊天列表里的中文名。步骤见 [3.2](#32-telegram-公开频道怎么加)。Docker 里 Telethon 已登录时走 `GetHistory` 增量；**未登录**才回退 `t.me/s`。已登录后失败会记为错误，不再悄悄改走网页。
- **微信公众号**：把 WeWe RSS 或任意 Atom 地址填进「RSS / WeWe」栏。**也可用「CSV 批量」一次导入多个账号**（见下）。
- **B 站 / YouTube**：分别填 UP `mid`、Channel ID。接口被风控时记到任务错误。
- **抖音 / 小红书 / 西瓜**：有 RSSHub 或自建 collector 时，把 URL 填进 RSS 栏。

间隔建议：快讯 5 分钟，专栏 30 或 60 分钟，深度长文每天一次。停用信源不会删除已入库内容。

**B 站特别提示（2026-09-17 实测）**：B 站接口有风控，返回 `-799 请求过于频繁` 时任务会标为**限流**（不是普通失败），需要退避等待。因此 B 站建议**不低于 6 小时**一次，过于频繁只会持续触发风控而不是更快拿到新内容。

### 3.1 微信公众号 CSV 批量导入（已上生产）

「信源 → 接入 → 平台选微信公众号 → CSV 批量」，上传 `.csv` 或直接粘贴。表头必须完全一致：

```csv
name,wechat_id,sample_url,primary_feed_url,interval_minutes,priority
示例科技,gh_example,https://mp.weixin.qq.com/s/example,https://feeds.example.com/example.atom,60,normal
```

- `name`、`wechat_id`、`sample_url`、`primary_feed_url` 必填；`interval_minutes` 固定 `60`；`priority` 留空按 `normal`，也可填 `high`。
- 文件 UTF-8；支持 BOM、CRLF、带逗号的引号字段与双引号转义。单文件 ≤ 1 MiB、≤ 1000 行。
- **预览不写库**：勾选有效行后点「确认导入」才写入。大小写不同的重复 `wechat_id`、库里已有的账号都会标为重复。
- 每行先幂等配置网关，**网关成功后才写数据库**；单行失败不阻断后续行。

> ⚠️ 上面的示例行是**虚构数据**。实际导入时 `sample_url` 必须是真实的 `https://mp.weixin.qq.com` 原文链接，
> `primary_feed_url` 必须是真实可用的 Feed。网关只接受 `WECHAT_PRIMARY_ALLOWED_HOSTS`
> 白名单里的主源域名（本机 wewe-rss 部署为 `host.docker.internal`，见
> `env-templates/README.md`）——域名不在白名单时真实 Feed 会被拒绝。
> （2026-09-30 曾发现该值被误配为 QA 夹具值 `wechat-fixture` 并已修复，事故记录见
> `operations/loom-source-errors-fix-2026-09-30.md`。）

### 3.2 Telegram 公开频道怎么加

接入用的是资料页上的 **英文用户名**（`@chqq888888` 里的 `chqq888888`），不是聊天列表里的中文标题。

1. 打开 Telegram 频道资料，复制链接 `https://t.me/用户名` 或 `@用户名`。没有 `@`、只有 `t.me/+…` / `joinchat` 的是私密频道，当前加不进去。
2. 织识左侧 **信源 → 接入**，平台选 **Telegram**。
3. 单个：名称随便填；**频道用户名**贴用户名或完整 `t.me/用户名`。**RSS 栏留空**（填了会走 RSS，不走 Telethon）。
4. 多个：用 **批量频道**，每行一个，最多 1000。可以混用用户名和链接：

```text
durov
telegram
https://t.me/chqq888888
```

5. 间隔建议先 **每 30 分钟**（快讯可用 10 分钟）。第一天不要一次加几十个，避免 FloodWait。
6. 点 **加入矩阵** / **批量加入**。已存在的用户名会跳过。
7. 在该行点 **扫描**，再打开 **任务** 看通道徽章。

可填：`chqq888888`、`@chqq888888`、`t.me/chqq888888`、`https://t.me/chqq888888`、`https://t.me/s/chqq888888`。  
不要只填 `t.me`，也不要把「彩虹成都气球」这类中文名当用户名。旧解析曾把 `t.me/chqq888888` 吃成 `tme`，扫描就会去打一个不存在的频道。

任务页怎么判断走了哪条通道：

| 你看到的 | 含义 |
| --- | --- |
| 绿色 **Telethon**，发现几十、新增大于 0 | 账号通道，第一次追上 |
| 绿色 **Telethon**，发现 0 / 新增 0，状态 `ok` | 已经追上，暂时没新帖 |
| 黄色 **t.me/s**，发现约 20 / 新增 0 | 网页预览（未登录，或旧任务） |
| 状态 `error`，尝试仍是 Telethon | 已登录但这次失败，**不会**再用网页 20 条充数 |

官方号「Telegram」的登录通知、没有公开用户名的群，不要当频道加。worker 读频道时可能加入该频道，只加你愿意用这个号加入的公开源。当前扫描先收文字和元数据；视频文件不在扫描时下载，需要落盘时用 **节点 → 媒体落盘**。

## 4. 关键词雷达

一个词是一条监听器，不是一次性搜索。到期后：

```
设定词 + 间隔 + 平台
        ↓
新闻 RSS / HN / B站搜索 / YouTube
        +
已接入信源正文匹配
        ↓
URL / external_id 去重
        ↓
items.matched_keywords
        ↓
内容库过滤 / 知识问答
```

- 逗号、顿号或换行分隔，一次最多 20 个词，每词 2–40 字。
- 「检索」平台会去公开搜索源拉新条目；「信源」平台只给已入库内容打标。
- 「立即收集」不等到期；「暂停」停调度；「移除」只停监听，条目保留。

## 5. 内容、OCR / ASR、知识库

每条内容归一化为：标题、正文、作者、链接、形态、媒体 URL、浏览量、发布时间、平台。

- **LLM 分析** — 摘要、主题、实体、洞察。
- **OCR / ASR** — 图片走视觉识别，音视频走语音转写，结果写回正文。
- 知识库只引用已采集材料。没有 `XAI_API_KEY` 时会明确提示，不会伪造回答。

## 8. Docker 生产（推荐，真正扫 Telegram）

到 [my.telegram.org](https://my.telegram.org) 申请 `api_id` / `api_hash`。本机需要 Docker Compose。

**先设这 8 个变量**（工作树版本已改为必填：缺任何一个，`docker compose up` 会直接报
`required variable XXX is missing a value` 并拒绝启动，而不是用公开默认口令跑起来——已实测）：

```bash
# 必填：缺一个 compose 就拒绝启动
export POSTGRES_USER=loom
export POSTGRES_PASSWORD="$(openssl rand -hex 24)"
export POSTGRES_DB=loom
export MINIO_ROOT_USER=loom
export MINIO_ROOT_PASSWORD="$(openssl rand -hex 24)"
export CRON_SECRET="$(openssl rand -hex 32)"
export WECHAT_GATEWAY_TOKEN="$(openssl rand -hex 32)"
export WECHAT_PRIMARY_ALLOWED_HOSTS=你的Feed域名          # 多个用逗号分隔

# 可选：Telegram 与模型
export TELEGRAM_API_ID=你的数字id
export TELEGRAM_API_HASH=你的hash
export XAI_API_KEY=可选，开 OCR/ASR/LLM
```

> **注意**：上面这一段描述的是**工作树（最新代码）**的行为。解压出来的 zip 里是 8 月版本，
> 其 compose 用的是 `${VAR:-默认值}` 形式，不会拒绝启动——**但那意味着它会用公开默认口令跑起来**，
> 所以**无论如何都要显式 export 这几个变量**。
>
> 变量**不要**写进仓库、不要放进命令行参数（`compose up` 会把命令行变量注入全栈，
> 本项目已因此发生过一次生产事故——见运行手册）。

```bash
# 交互登录一次（手机号 + 验证码）
docker compose run --rm -it telethon python login.py

# 启动 Postgres + MinIO + Telethon + 控制面
docker compose up --build
```

启动后：

- 控制面对外提供服务；MinIO 控制台在 9001。会话写在 volume，不必每次登录。
- **默认只绑定本机回环**（`127.0.0.1:8080`）。要让别的机器访问，必须显式改端口映射，
  并先想清楚应用**没有登录**这件事。
- 登录前 Telegram 自动回退公开网页预览，控制面照常可开。
- 信源页选 Telegram，每行一个**用户名或 t.me 链接**（最多 1000）。间隔建议 10–30 分钟。见 [3.2](#32-telegram-公开频道怎么加)。
- 「节点」页应看到 Telethon 已登录、MinIO 在线。点「媒体落盘」把远程文件写入 bucket `loom`。
- **桶的默认可见性随版本而定**：工作树版本默认**私有**（`MINIO_BUCKET_ACCESS=private`，要公开得显式设为 `public`）；
  8 月的 zip 版本则**硬编码为匿名可读**。只对确实是公开材料的素材开放匿名访问。
- OCR / ASR 默认按键触发。`EXTRACT_AUTO=true` 才会在扫描时自动提取（消耗额度）。
- `TICK_LIMIT` 默认 20，即每轮最多扫 20 路到期信源 / 关键词。

## 9. 日常操作顺序

1. 关键词页设定行业词，确认立刻收集有命中。
2. 信源页接入 RSS / Telegram 频道。
3. 总览点「扫描到期」，或等页面可见时约每 2 分钟自动 tick。**关掉浏览器也不影响采集**——编排容器每 60 秒唤醒一次。
4. 内容库过滤查看；重要条目做分析或 OCR/ASR。
5. 知识库生成今日简报，或直接提问。
6. 任务页核对失败原因（风控、FloodWait、未登录）。
7. 节点页确认生产组件；需要时点媒体落盘。

## 10. 常见问题

| 现象 | 处理 |
| --- | --- |
| `docker compose up` 报 `set XXX` | 工作树版本的 compose 要求 8 个必填变量；照第 8 节先 export。这是刻意设计，防止用公开默认口令跑起来。 |
| 节点页 Telethon / MinIO 显示未配置 | 预览里正常。本机请按第 8 节 `docker compose up`。 |
| Telegram 任务报未登录 | 再跑一次 `login.py`，确认会话写进 volume。重建 Telethon 时要用带 `TELEGRAM_API_ID` / `HASH` 的项目根目录 `.env`，空值会冲掉凭据。 |
| 任务出现 FloodWait | 节点会自动推迟，任务记为 Telethon 错误，不会改走网页。降低并发或把间隔调到 10/30 分钟。 |
| 信源变成 `tme`，或报 JSON / `500 Internal Server Error` | 把完整 `t.me/用户名` 当成了域名。应填 `chqq888888` 或 `https://t.me/chqq888888`。停用错误行，用正确用户名重新接入。 |
| 任务发现约 20、新增 0，徽章是 t.me/s | 网页预览。先看节点页是否「已登录」。已登录却仍如此，把任务原文发运维（不要发验证码）。 |
| 任务发现 0、新增 0，徽章是 Telethon、状态 ok | 正常，已经追上。 |
| OCR / ASR 提示没有密钥 | 设置 `XAI_API_KEY`。模型只在按键时调用。 |
| 微信没内容 | 上游风控致正文全空，**当前不纳入首版**。CSV 批量导入界面可用，但拿不到正文。 |
| 抖音 / 小红书 / 西瓜没内容 | 无内置全站检索。有自备 RSSHub / collector 时把 URL 填进信源 RSS 栏。 |
| 内容重复 | 同一 `(source_id, external_id)` 会去重。换词命中已有条目只打标。 |
| 批量频道没全部扫到 | 每轮只扫到期的前 `TICK_LIMIT` 路，下一轮继续。 |
| 图片打不开（自建部署） | 工作树版本桶默认私有。确认素材确实是公开材料后，设 `MINIO_BUCKET_ACCESS=public`。 |
