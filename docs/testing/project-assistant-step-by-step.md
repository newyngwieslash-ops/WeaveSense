## 2. 最小端到端用例顺序

纯读 → 关键词预览/批准 → 确认列表变化 → 指定关键词采集 → 确认真实jobs状态 → 引用采集内容启动研究 → 审核发布 → 多轮追问 → 运行中刷新 → 取消 → 故障恢复。

业务验收指令（A29）："监测GLP-1和药品集采，每30分钟检查新闻/RSS与B站，现在各运行一次，告诉我本次新增内容和失败范围。"
空库预期：2个create加2个collect_once共4动作；存在旧规则时如实返回existing，配置不一致先解决。隔离测试暂停cron/首页tick，通过action→job区分本次扫描与自动调度。
